# Apps

One list for every Mac. Remove what you don't need before running the install.

## Install

CLI tools:

```bash
brew install git lazygit starship vim yazi
```

Apps:

```bash
brew install --cask \
  appcleaner \
  cursor sublime-text \
  google-chrome firefox zen-browser \
  ghostty font-hack-nerd-font \
  docker-desktop jetbrains-toolbox postman yaak drawio \
  notion obsidian linear-linear \
  raycast rectangle itsycal stats \
  slack microsoft-teams zoom \
  adobe-acrobat-reader pdf-expert \
  claude notchnook logitech-g-hub \
  anki discord spotify
```

Update later with `brew upgrade`; list what is installed with `brew list`.
