# macOS Settings

System settings worth changing on a new Mac. Menu names can differ slightly between macOS versions; search the setting name in _System Settings_ if you can't find it.

## Menu bar always visible

By default macOS hides the menu bar for apps in full screen.

_System Settings → Control Center → Menu Bar → Automatically hide and show the menu bar_ → **Never**

On older macOS: _Desktop & Dock → Automatically hide and show the menu bar in full screen_ → off.

Verify: put any app into full screen; the menu bar stays visible.
