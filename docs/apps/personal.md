# Personal Apps

Same base as work, minus work comms and heavy tooling.

**Removed from work:** `slack`, `microsoft-teams`, `zoom`, `linear-linear`, `adobe-acrobat-reader`, `pdf-expert`, `drawio`, `logitech-g-hub`, `notchnook`

## Install all at once

```bash
brew install git lazygit starship vim yazi
```

```bash
brew install --cask \
  appcleaner \
  cursor sublime-text \
  google-chrome firefox zen-browser \
  ghostty font-hack-nerd-font \
  docker-desktop jetbrains-toolbox postman yaak \
  notion obsidian \
  raycast rectangle itsycal stats \
  claude \
  anki discord spotify
```
