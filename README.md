# dotfiles

Personal developer toolkit — dotfiles, app configs, and onboarding docs for Mac web dev setup.

## Structure

```
configs/       App configs (Ghostty, Starship)
docs/          Onboarding guides
dotfiles/      Shell configs and Claude Code commands
work/          Work-specific dotfiles and commands
```

## Docs

- [Mac Setup](docs/setup.md) — new Mac: base steps, then one guide per tool
- [Guides](docs/README.md) — Homebrew, Git, terminal, shell, Node, Java, Claude Code
- [Git & SSH](docs/guides/git.md) — git identity, defaults, SSH keys for GitHub & GitLab
- [Writing Skills](docs/writing-skills.md) — how to write Claude Code commands/skills
- [Claude Code Best Practices](docs/claude-code-best-practices.md) — workflow habits
- [Starship](docs/guides/starship.md) — prompt setup
- [Apps](docs/apps.md) — one list of all apps and CLI tools
